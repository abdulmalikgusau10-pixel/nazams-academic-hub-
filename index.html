Ask. Understand. Revise.

Planned capabilities include explaining medical concepts, summarising notes, generating MCQs, explaining past questions, creating flashcards and preparing level-appropriate revision plans.

NAZAMS AI is currently a design placeholder, not a live chatbot. When connected, it will require mobile data or Wi-Fi and a secure AI service/API. Usage may have free limits or costs. Never place private API keys in this website's public code.

Assessment and grading plan

Each assessment can record marks, percentage, time taken, correct and incorrect answers, subject performance and revision recommendations. Grade boundaries will be configurable to match each participating school's approved system and the student's 100L, 200L or 300L level.

Scores cannot yet be saved to a shared student account. Persistent performance history requires the secure database and student login system.
